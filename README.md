 StudyCart 2026 🎨

Best for Kids, Given with Love 💜

A complete stationery e-commerce website for Sri Lankan families, built with vanilla HTML, CSS, and JavaScript.

 🚀 Features

- 🛍️ 16 stationery products across 4 categories
- 🔍 Live search & category filter
- 🛒 Editable cart saved in the browser (add / remove / change quantity)
- 🧾 3-step demo checkout with cash on delivery; no real order or payment processing
- 🏷️ Optional KIDS10 discount code
- 🚚 Delivery details with all 25 Sri Lankan districts
- 📱 Fully responsive design
- 🎨 Beautiful gradient colors & animations
- 🌐 No frameworks — pure vanilla JS
- ✉️ Contact form is a local demo and does not send messages

- JavaScript (ES6+) — Vanilla, no frameworks
- Google Fonts — Inter
- Font Awesome 6.4.0 — Icons

 🚀 How to Run

1. Download or clone the project
2. Open `index.html` in any modern browser
3. That's it! No build step needed. Internet access is required for Google Fonts and Font Awesome icons.

 💡 Customization

- Products: Edit `data.js`
- Colors: Change CSS variables in `style.css` (`:root`)
- Discount: Update `DISCOUNT_RATE` in `helpers.js`
- Delivery Fee: Update `DELIVERY_FEE` in `helpers.js`

 📦 Deploy

Works on any static host:
- GitHub Pages
- Netlify
- Vercel
- Any web server
